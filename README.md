# AZYON: Rift Chess

Браузерные шахматы для двух игроков на одном устройстве. Правила, проверка допустимости ходов, шах, мат, пат и ничьи реализованы библиотекой `chess.js`.

## Возможности

- Рокировка, взятие на проходе и превращение пешки.
- Перетаскивание фигур и выбор хода нажатием на клетки с подсветкой доступных ходов.
- История партии в шахматной нотации.
- Отображение текущего игрока, шаха, мата, пата и ничьей.
- Рифт-комбо: серия взятий подряд и личный рекорд серии в текущей сессии.
- Адаптивная доска и кнопка новой партии.

## Запуск локально

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
npm run preview
```

## Публикация

GitHub Actions автоматически собирает проект и публикует папку `dist` в GitHub Pages после каждого изменения ветки `main`. Результат будет доступен по адресу `https://REst12231312.github.io/Ayzon-Chess/` после успешного первого запуска workflow.
